長穩智能科技FMS廠務管理App

原先FMS廠務系統以管理者使用的 Web 平台為主,現場工務人員雖可透過手機登入操作,但介面層級複雜、分類過 多,與實際作業情境不符。日常需頻繁登入登出、手動填寫巡檢資料並查找設備資訊,不僅耗時,也容易產生錯誤。 隨著廠區規模擴張,巡檢、抄表與保養等作業量增加,手動回報流程成為現場效率與資料即時性的主要瓶頸。為解決此 問題,我們設計 FMS 行動 App,協助工務人員於現場即時記錄作業並完成電子簽核,簡化流程、降低人工負擔,並同 步將資料回傳至管理端。

Design Guideline

產品設計規範

字體與配色

採用poppins無襯線字體，標題22~18px、內文 12~16px，行高與字距微調增進閱讀舒適度。配色以藍色 為主，輔以綠色強調，並用三種灰階作為背景和次要文字，兼顧FMS品牌調性與清晰度。

元件規格

所有元件皆採卡片化風格：20px圓角、8~16px基本間距。按鈕分實底與細框兩種樣式，含 Hover/Disabled 狀態；表格與輸入框維持 16px 內邊距與細線框；Icon 採 24×24px 線性風格，主色與灰階提示互動狀態。

User Interface Design

設備掃碼作業

快速掃碼定位設備,整合記錄查詢,降低人工錯誤。

掃碼快速識別

掃描設備QR Code， 即時帶出設備資訊與 作業內容。

查閱設備詳細資料

顯示設備位置、狀態與維修紀錄，資訊一目了然。

填寫作業紀錄

簡化流程、即時填寫設備狀況與現場處置建議。

User Interface Design

維修單

掃碼建單直覺快速,回報異常 狀況,提升報修效率與正確性。

掃碼快速新增故障設備

掃描設備條碼，自動帶入設備資訊並建立維修單。

選擇故障類別

從下拉選單中快速勾選異常狀況，減少輸入錯誤。

填寫故障說明

補充異常情形、處置建議。一鍵提交維修單，後續進入簽核與處理流程。 提升溝通效率。

User Interface Design

工作日誌

自動整合今日進度,輔助 交接與簽核,大幅減少手動錯誤。

自動導入今日工作進度

系統自動帶入已完成與待處理項目，免手動輸入提升效率。

填寫與簽核工作紀錄

除工作進度外，也可補充交接事項， 讓主管線上簽核確認。
