長穩智能科技FMS廠務管理App

原FMS廠務管理以管理端Web為主，但現場工務/維修人員用手機操作時，常得多層查找、反覆登入，巡檢與報修回報慢且容易漏填。隨廠區擴張，手動回報成為效率與即時性的瓶頸。 我負責此專案的redesign進行 UX 研究、資訊架構與 UI 設計，將流程重構為行動 App：以「掃設備 QR Code」作為單一入口，整合設備資訊、任務記錄與電子簽核，讓現場能即時回報、降低人工錯誤，並把資料同步回傳管理端以利追蹤與稽核。

Design Guideline

產品設計規範

字體與配色

採用poppins無襯線字體，標題22~18px、內文 12~16px，行高與字距微調增進閱讀舒適度。配色以藍色 為主，輔以綠色強調，並用三種灰階作為背景和次要文字，兼顧FMS品牌調性與清晰度。

元件規格

所有元件皆採卡片化風格：20px圓角、8~16px基本間距。按鈕分實底與細框兩種樣式，含 Hover/Disabled 狀態；表格與輸入框維持 16px 內邊距與細線框；Icon 採 24×24px 線性風格，主色與灰階提示互動狀態。

User Interface Design

設備掃碼作業

捨棄 Web 版層層篩選的選單邏輯，改以 QR Code 作為現場作業的單一入口。工務人員無需記憶複雜編號或手動搜尋，掃描即可直達目標設備頁面並自動帶入基本資訊。這不僅讓「定位設備」的時間趨近於零，更從源頭杜絕了「填錯設備單」的人為疏失。

掃碼取代搜尋，縮短查找時間

相對 Web 需要多層選單與關鍵字搜尋，掃碼即可帶出設備與待辦作業，降低找錯設備的風險。

設備資料一致化，歷史紀錄可追查

集中呈現位置、狀態與維修紀錄，讓現場判斷更快，也讓後續追查有依據。

少輸入、少錯誤，現場即填即回傳

表單欄位精簡並搭配預設值/選項，降低手動錯誤，資料同步回傳管理端提升即時性。

User Interface Design

維修單

將原本分散的報修欄位整合為線性引導流程。系統自動帶入當前設備資訊，人員僅需勾選故障類型並補充故障說明，即可一鍵送出。針對多設備故障場景，設計了「批次新增」模式，避免在列表頁與詳情頁間反覆跳轉，大幅提升突發狀況下的通報效率。

掃碼自動帶入，避免設備對不上

相對 Web 手動挑選設備容易選錯，掃碼可直接鎖定設備，減少來回確認與補件。

故障分類結構化，便於統計與分派

用選項取代自由輸入，讓資料格式一致，後端能更快做分派與分析。

一次提交串接簽核，縮短溝通成本

把「描述異常→送出→進入處理流程」拉成一條線，減少跨班交接的資訊落差。

User Interface Design

工作日誌

工務人員常需在一天結束後憑記憶補寫日誌。新設計將日誌轉化為「自動彙整」的儀表板，系統自動抓取當日已完成的巡檢與維修紀錄，自動生成日誌草稿。人員僅需確認並補充交接事項即可簽核，將行政工作對現場作業的干擾降至最低。

自動彙整進度，降低漏寫與重工

系統自動帶入已完成與待處理項目，免手動輸入提升效率。讓日誌變成「確認＋補充」，而不是重新輸入一遍。

交接資訊一致，主管可即時核准

補充交接事項並線上簽核，縮短等待時間，也讓紀錄可追溯。
