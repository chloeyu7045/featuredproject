Bqool AdvertisingAmazon Advertising Management Software

This is a one-stop advertising management tool built specifically for Amazon sellers. Powered by AI bidding algorithms and automatic optimization modules, it dynamically adjusts bids and strategies based on real-time ad performance to continually improve ROI and operational efficiency. Following a user-centered design philosophy, the interface features clear visual hierarchy and modular layouts, helping sellers efficiently manage multi-market campaigns from a single platform.

Design Guideline

Grid

Uses a responsive 12-column grid with 24 px gutter and 16 px side margins. On mobile it collapses to 4 columns, tablet to 8, desktop to 12—keeping alignment consistent across devices. Key sections can span multiple columns and are centered with generous white space to draw attention.

Typography & Color

Typeface: Inter (sans-serif). Headings: weight 600–700; body text: 400. Line-height and letter-spacing are fine-tuned for readability. Primary color is purple with blue accents; three shades of gray serve as background and secondary text to balance brand tone and clarity.

Component

All components use a card style with 8 px border-radius, 4 × 4 × 8 px 20% shadow, and 32 px default spacing. Buttons come in filled and outlined versions, with hover/disabled states. Tables and inputs have 16 px padding and thin borders. Icons are 20 × 20 px line style, using primary color and gray to indicate interactive states.

User Interface Design

Dashboard

Performance Overview

A set of Performance Cards shows core metrics—Total Sales, Ad Sales, Ad Spend, ACOS—along with colored percentage indicators comparing to the previous period. Users can customize which metrics to monitor so the dashboard aligns with their business goals.

Performance Over Time

Line charts visualize time-series ad metrics, defaulting to Ad Sales vs. Ad Spend and Ad Orders vs. ACOS. Users can swap in different indicators to spot long-term trends and anomalies.

Preview Report

Aggregates dashboard data into a downloadable, shareable report. In the preview, users select key metrics and charts, remove anything unnecessary, and export a polished performance report with one click—for internal review or client presentations.

User Interface Design

Ad manager

AI Bidding

Automatically analyzes daily ad performance against the user’s Target ACOS and dynamically adjusts bids. This reduces manual work and keeps campaigns within the desired ACOS range.

Auto-Harvesting

Each day the tool scans search term reports, selects high-performing keywords for inclusion, and isolates low-performers as negatives. New relevant terms are added to campaigns automatically, continuously refining targeting and cutting out manual keyword management.

Filter

Offers multi-dimensional filters—Marketplace, Campaign Type, Status (Active/Paused), ACOS range, etc.—applied instantly to the data grid. Users can zero in on specific campaigns without digging through lengthy reports, boosting day-to-day management and optimization workflows.

Hierarchy Tabs

Simplifies Amazon’s six-layer ad structure by combining Campaign, Ad Group, Keyword, Target, Product Target, and Search Term into one tabbed interface. Users switch levels with one click, retaining hierarchical logic while analyzing data intuitively. Each tab supports sorting and column customization to streamline operations.

User Interface Design

Campaign Builder

Campaign Builder guides sellers through a structured, modular workflow for creating campaigns. Users pick an AI strategy module based on their marketing objective, select products at multiple levels, and set automatic bidding. This significantly speeds up campaign setup while ensuring each campaign follows best-practice structure and resource allocation. The guided flow suits both beginners and advanced users, enabling replicable, standardized campaign creation.

Goal Strategy

Provides four template strategies—Basic, Advanced, Brand-Based, Custom—tailored to different objectives. An inline diagram previews the resulting Campaign + Ad Group structure, helping users quickly understand and choose the right approach.

Products

Supports product search by ASIN, SKU, or name, and toggling between Child-View and Parent-View for variant hierarchies. Selected products gather on a right-hand list where items can be removed individually or cleared all at once. The system warns if an ASIN is already in a running campaign to avoid duplication.
